# 禁止自动修改 .env 文件规则

## 核心约束

**禁止自动修改、创建或更新 .env 文件中的任何内容，所有变更必须由用户手动操作。**

## 详细说明

1. **禁止自动写入**：不得通过工具（SearchReplace、Write 等）直接修改 `.env` 文件的内容，包括但不限于：
   - 新增环境变量
   - 修改现有变量的值
   - 删除变量或注释
   - 调整格式或排列顺序

2. **可以做的事**：
   - **读取** `.env` 确认变量是否存在、配置是否完整
   - **告知用户**需要添加或修改哪些变量（给出变量名和说明，不给具体值）
   - **提供模板**：在对话中展示需要添加的变量格式，由用户自行复制粘贴到 `.env`
   - 回复中引用变量名（不回显明文值，遵循 `no-echo-secrets.md`）

3. **需要新增配置时的正确做法**：
   ```
   请在 .env 中添加以下配置：
   OSS_BUCKET_NAME=<你的 Bucket 名称>
   OSS_ENDPOINT=oss-cn-beijing.aliyuncs.com
   ```
   而不是直接帮用户写入文件。

4. **例外情况**：仅在用户明确要求「帮我写到 .env」且给出具体值时，才可执行写入操作，但仍需先确认。

## 背景与解决的问题

> **为什么需要这条规则**：2026-07-03 构建 CosyVoice Demo 时，多次自动修改 `.env` 文件（新增 OSS 配置、修改 Bucket 名称等）。
> `.env` 包含 API Key、AccessKey 等高敏感凭证，自动修改可能导致：
> - 误覆盖用户已有配置
> - 写入不正确的值导致调试困难
> - 暴露敏感信息的变更历史
> **解决什么问题**：将 `.env` 的修改权限完全归还用户，Agent 只负责读取和提示，不主动操作。
