# 禁止 rm -rf 命令规则

## 核心约束

**禁止在任何场景下执行 `rm -rf` 命令。**

## 详细说明

1. **绝对禁止**：无论目标路径是什么，均不得执行 `rm -rf` 或等价命令（如 `rm -r -f`、`rm --recursive --force`、`rm -Rf` 等变体）

2. **替代方案**：
   - 删除单个文件 → 使用 `DeleteFile` 工具（安全删除，有确认机制）
   - 删除目录 → 先列出内容确认无重要文件，再逐文件用 `DeleteFile` 删除
   - 批量清理 → 与用户确认目标范围后，建议用户手动执行

3. **即使用户明确要求**：
   - 不得直接执行 `rm -rf`
   - 应提醒用户该命令的高风险性（不可恢复、可能误删）
   - 建议用户自行在终端中执行，Agent 不代为操作

4. **Bash 工具约束**：
   - 在 `Bash` 工具中执行任何 `rm` 命令时，必须设置 `has_risk: true`
   - 禁止使用 `-f`（force）参数，必须保留交互式确认
   - 禁止使用 `-r`/`-R`（recursive）参数删除整个目录树

## 允许的操作

- `rm` 单个文件（无 `-r` 参数，且设置 `has_risk: true`）
- `DeleteFile` 工具删除文件
- 用户明确确认后的其他低风险清理操作
