值得关注的信号

DeepSeek 将 "Harness" 提升为核心学科

Harness 源自 test harness / eval harness 等既有概念。DeepSeek 将其从"评测框架"扩展为"模型之外的一切"——上下文管理、工具调用、记忆、子 Agent 调度、评测基准等，并以 Model + Harness = Agent 的公式确立其与模型并列的地位。

Claude Code 是出现频率最高的外部产品

几乎每个 Agent 相关岗位都提到 Claude Code，其次是 Cursor、OpenClaw、Manus。DeepSeek 显然在密切跟踪这些竞品的能力边界。

"Vibe Coding" 被正式写入 JD

全栈工程师岗位要求候选人是"Vibe Coding 重度用户"，说明 AI 辅助编程已成为 DeepSeek 内部的标准工作方式。

强化学习是 Agent 训练的核心手段

PPO、DPO、RLHF/RLAIF 不仅是算法岗的要求，连数据策略工程师和全栈工程师都需要理解其概念。RL 渗透到几乎所有 Agent 岗位。

桌面端 Agent 产品是重点方向

多个 Harness 岗位明确提到"桌面端 Agent 产品研发"，说明 DeepSeek 正在打造类似 Cursor/Claude Code 的桌面级 AI 开发工具。

从数据到模型的完整闭环

"数据-训练-评测"闭环反复出现在多个 JD 中。数据策略、预训练数据、模型策略产品经理都在强调这种端到端迭代能力。
