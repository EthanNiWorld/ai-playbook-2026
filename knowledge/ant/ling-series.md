### Ling-3.1-flash
- 模型：`antdigital/Ling-3.1-flash`（百炼模型代码）
- 公司：蚂蚁集团百灵团队；百炼推理服务供应商为蚂蚁数科（Ant Digital）
- 时间：2026.09.30 发布（IT之家）
- 尺寸：总参数约 560B，每 Token 激活约 25B（MoE）
- 上下文：1M（1,048,576）；最大输出 262,144（256K）；思考模式下最大输入 1M / 最大输出 256K / 最大思维链 256K
- 场景：通用智能体、搜索、日常办公、软件研发；医疗、金融、材料科学研究（官方优化方向）
- 特点：
  - 仅文本输入/输出；Function Calling、结构化输出、前缀续写、上下文缓存均支持
  - 不支持：模型体验、联网搜索、批量推理、模型调优（百炼版）
  - OpenAI 兼容接口调用
- 定价：百炼华北2（北京）原价 输入 ¥2 / 输出 ¥6 / 缓存命中 ¥0.4（每百万 Token）；限流 RPM 300 / TPM 10,000,000

## 核心能力与限制

### 核心能力

| 能力 | 说明 |
|------|------|
| 长上下文 | 1M 上下文 + 256K 最大输出（含思考模式），可容纳长文档/代码/任务历史 |
| MoE 高效推理 | ~560B 总参 / ~25B 激活，Flash 档成本结构 |
| Agent 工具链 | Function Calling + 结构化输出 + 前缀续写 + 上下文缓存 |
| 思考模式 | 支持，最大思维链 256K |
| 生态兼容 | OpenAI 兼容接口，百炼标准调用方式 |

### 核心限制

| 限制项 | 具体值 | 说明 |
|--------|--------|------|
| 模态 | 仅文本输入/输出 | 多模态需求需看 Ling-3.0-flash-VL（未上架百炼，待核实） |
| 联网搜索 | 不支持 | 需外挂搜索工具 |
| 批量推理 / 模型调优 | 不支持 | 百炼版能力边界 |
| 限流 | RPM 300 / TPM 10M | 高并发场景需评估（对比：百炼多数模型 RPM 更高） |
| 节点覆盖 | 百炼页面仅展示华北2（北京）定价 | 国际站节点未展示（2026-11-11 核实） |

## 适用场景

### ✅ 适用

| 场景 | 推荐模型 | 说明 |
|------|----------|------|
| 通用智能体 / 办公自动化 | Ling-3.1-flash | 官方主打场景，FC + 结构化输出齐备 |
| 长文档 / 代码库理解 | Ling-3.1-flash | 1M 上下文 + 256K 输出 |
