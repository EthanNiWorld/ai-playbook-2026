## 是什么

模型自我进化能力（Self-Evolution）是指模型深度参与自身迭代优化过程的一种新范式：

- **传统范式**：人工设计训练流程 → 人工标注数据 → 模型训练 → 人工评估
- **自我进化范式**：模型自主构建训练脚手架 → 自主驱动强化学习 → 自主优化学习过程

## 核心原理

### 技术机制

以 MiniMax-M2.7 为例，其自我进化包含三个关键能力：

1. **自行构建 Agent Harness**：模型能够自主设计评估脚手架和训练框架
2. **更新 Memory**：模型能够管理自身记忆系统，优化知识组织
3. **驱动强化学习**：模型自主决定训练信号和优化方向

### 量化效果

> MiniMax-M2.7 自主运行超过 100 轮迭代优化脚手架，最终效果提升 **30%**。

这说明：
- 模型的提升空间可能远超人工设计的天花板
- "模型教模型"的效果可以超过"人工教模型"

## 为什么重要

### 打破人工瓶颈

传统模型训练的瓶颈在于：
- 人工设计训练流程存在认知天花板
- 人工标注数据的规模和成本有限
- 评估标准依赖人工定义，难以捕捉模型潜力

自我进化打破了这一瓶颈：
- 模型可以发现人工无法设计的训练路径
- 可以自主生成高质量训练信号
- 可以定义更精准的自身评估标准

### 范式转变意义

| 维度 | 传统范式 | 自我进化范式 |
|------|---------|-------------|
| 训练设计 | 人工设计 | 模型自主构建 |
| 数据生成 | 人工标注 | 模型自主生成 |
| 评估标准 | 人工定义 | 模型自主优化 |
| 迭代方向 | 人工决定 | 模型自主探索 |

## 关键洞察

### 核心洞察：AI 能力提升的新阶段

**现象**：M2.7 实现了"模型自己驱动自身训练"，100+ 轮自主迭代带来 30% 效果提升

**本质**：这是 AI 能力提升从"辅助工具"到"自驱动系统"的质变时刻——模型从"被训练的对象"变成"主动提升自己的主体"

**为什么重要**：这意味着 AI 能力的提升不再是线性的人工投入，而是可能指数级增长的自我优化过程

**可迁移场景**：
- 企业训练 Agent 时可借鉴"让模型参与设计自身评测"的方法
- 产品设计时考虑模型的自我优化能力边界
- AI 系统的评测标准需要从"人工打分"转向"模型自评"

## 两条工程路径（2026-09 新进展）

2026 年 9 月，两家中国厂商在同一周把 self-improvement 写进发布叙事，但指向两条本质不同的路径。这为判断"自我进化"类宣传提供了可操作的分辨框架。

| 维度 | 腾讯 Hy4 preview | 小米 MiMo-V2.6 |
|------|------------------|----------------|
| 改进对象 | **自身研发与推理栈**：训练方法、数据策略、评测框架、底层算子、推理系统 | **自身策略能力**：在环境中反复试错变强 |
| 机制 | 模型提方案 → 跑实验 → 按结果迭代，代码/日志/反馈进入下一轮 | You Only RL Once：多域 + 多 harness 混训 + 组内比较奖励 + 异步 GRPO |
| 可验证产出 | 推理栈端到端吞吐 +31.8% | 训练任务平均通过率 +25%；训练成本约 85 万美元 / 6 天 |
| 本质 | **流程内嵌**：模型作为研发执行者，缩短"人改模型"的循环 | **闭环规模化**：模型作为学习者，抬高"环境产信号"的吞吐 |
| 风险 | 自述不可复现、可能改写评测标准 | reward hacking（官方以冻结 router + 多层防御应对） |

**两条路径的底层约束不同**：
- Hy4 走流程内嵌，是因为旗舰模型的训练成本已高到"优化训练过程本身"比"再堆一轮预训练"更划算；同时有真实工程任务做 eval 闭环，模型"改自己"才有可验证的靶子。
- MiMo 走闭环规模化，是因为小模型（15B 激活）的天花板不在参数而在数据效率——把单条轨迹做便宜（SWA + 稀疏 MoE + MTP）、把奖励做细（GRS/GAR）、把轨迹复用做高（MOPD2），才能用 85 万美元买到 AA 38。
- 共同前提：**后训练（RL）已成为能力主战场，预训练规模化让位于"训练系统吞吐 × 反馈密度"**。

**判断自我进化真伪的两个标尺**：① 改进的是模型能力还是研发流程；② 是否给出可复现的量化产出（吞吐/通过率/成本）与开放的训练动态。只讲"模型参与研发"而不开放 eval 与训练细节的，应视为方向声明而非能力证明。

> 两条路径的完整事实与数据见 [混元系列](../tencent/hunyuan.md) 与 [MiMo-V2.6 系列](../xiaomi/mimo-v2.6-series.md)。

## 背景案例

### MiniMax-M2.7 实践

- **时间**：2026 年 1 月，MiniMax 上市后首份年报披露
- **核心能力**：模型深度参与自身迭代优化过程
- **具体表现**：
  - 自行构建 Agent Harness（训练脚手架）
  - 自主更新 Memory
  - 自主驱动强化学习
  - 自主优化学习过程
- **效果**：100+ 轮自主迭代 → 效果提升 30%

### 与 Agent 的关系

自我进化能力与 Agent 框架有天然的协同：
- Agent 的核心是"感知 → 思考 → 行动 → 观察"循环
- 自我进化让模型成为这个循环的"设计者"而不仅是"执行者"
- 未来的 Agent 可能不仅是执行任务的工具，更是能够自主改进自身的系统

## 相关概念

- **Harness**：模型的约束和评估框架，是自我进化的基础设施
- **强化学习（RL）**：自我进化的核心技术手段
- **Agent**：自我进化的主体形式之一
