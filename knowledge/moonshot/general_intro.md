> 最后更新: 2026-11-18
> **数据时效说明**：以下数据综合截至 2026 年 7 月公开披露（产品矩阵已同步 kimi-k-series.md 2026-11-13 口径，含 K3.1 Pro）。由于公司为私营非上市企业，财务与运营数据可能存在估算偏差，**使用前请务必交叉验证**。

## 一、公司概况

**北京月之暗面科技有限公司**（Moonshot AI）成立于 2023 年 4 月 17 日，总部位于北京市海淀区，是中国领先的大模型创业公司。公司法定代表人杨植麟，注册资本 100 万元人民币。

**成立时间**：2023 年 4 月 17 日  
**总部**：中国北京  
**性质**：私营非上市企业  
**现任 CEO**：杨植麟  
**总裁**：张予彤

## 六、技术路线与核心创新

### 5.1 架构创新

- **MoE（混合专家）架构**：1T 总参数，32B 激活参数
- **Muon 优化器**：首次在超大规模 MoE 模型中成功应用，解决训练不稳定性
- **MLA（Multi-head Latent Attention）**：高效注意力机制
- **KDA（Kimi Delta Attention）+ Attention Residuals**（K3，2026.07）：混合线性注意力 + 注意力跨层残差，百万 token 解码提速 6.3 倍，训练效率 +25%
- **MoonViT 视觉编码器**：原生多模态理解能力

### 5.2 Agent 能力演进

- **K2**（2025.07）：Tool Calling、自主问题解决
- **K2.5**（2026.01）：Agent Swarm（100 子 Agent 协作）
- **K2.6**（2026.04）：Agent Swarm（300 子 Agent）、Claw Groups（多 Agent 异构协作）、长周期执行（13 小时连续编码）
- **K3**（2026.07）：端到端知识工作（GDPval-AA Elo 1668，全球第 3）、视觉进入编程循环、1M 上下文长程任务

### 5.3 开源策略

公司采取积极开源策略，Kimi K2 系列模型权重和代码均以 Modified MIT License 开放，推动全球 AI 社区发展。

## 七、市场竞争格局

月之暗面与 DeepSeek 并列为中国大模型创业双雄，两者在技术路线上有显著差异：

- **DeepSeek**：聚焦推理能力（R1 纯 RL 推理）、训练效率（557 万美元训练 V3）
- **月之暗面**：聚焦 Agent 能力、长周期执行、多 Agent 协作

两家公司均在 2025-2026 年获得大规模融资，估值快速攀升。

## 九、技术演进与研究影响力

### 模型技术创新演进

> 独创性分级：🌟 首创 / 🔧 组合创新 / ⚙️ 工程优化 / 📋 跟进对齐（口径同 ai-native-expert「新模型发布分析框架」）。官方宣称的"首个"均标注"官方称"。架构细节见上方第六章与 [kimi-k-series.md](kimi-k-series.md)，本节只做逐代提炼与研判。

| 版本 | 时间 | 核心技术创新 | 独创性 | 能力/成本影响 |
|------|------|-------------|--------|--------------|
| **Kimi K2** | 2025.07 | 1T MoE + Muon 优化器首次超大规模成功应用（官方称）+ MLA | 🔧 组合创新 | 开源 Agent 能力基线，Tool Calling 自主问题解决 |
| **Kimi K2.5** | 2026.01 | 原生多模态（MoonViT）+ Agent Swarm（100 子 Agent） | 🔧 组合创新 | 多 Agent 协作产品化 |
| **Kimi K2.6** | 2026.04 | Agent Swarm 扩至 300 子 Agent + Claw Groups 异构协作 | ⚙️ 工程优化 | 13 小时长周期连续编码 |
| **Kimi K2.7-Code** | 2026.06 | 基于 K2.6 的编码专精后训练 | ⚙️ 工程优化 | 推理 token -30%，守 IDE 快速编码循环 |
| **Kimi K3** | 2026.07 | KDA 混合线性注意力 + Attention Residuals 跨层残差；2.8T MoE（稀疏度 1.8%）；MXFP4/MXFP8 量化感知训练 | 🔧 组合创新（线性注意力赛道已有先例，KDA+AttnRes 为自研组合） | 1M 解码提速 6.3×、训练效率 +25%；官方称全球首个 2.8T 级开源模型 |
| **Kimi K3.1 Pro** | 2026.10 | K3 后训练版：增加 RL 算力，改进长上下文推理/沙箱/任务调度/环境质量检查，架构不变 | ⚙️ 工程优化 | 定价 $2/$10 低于 K3；权重按期开放；本次无架构级创新披露 |

### 技术方向研判

- **技术主线**：长上下文（Kimi 助手）→ 开源 Agent 基线（K2）→ 多 Agent 协作（K2.5/K2.6 Swarm）→ 长周期编码与端到端知识工作（K2.6/K3）→ 后训练强化旗舰（K3.1 Pro）。与使命"能量到智能的最优转化"呼应，注意力效率与稀疏 MoE 是持续攻击目标
- **持续押注**：注意力机制降本（MLA → KDA+AttnRes）、超大稀疏 MoE（1T → 2.8T，激活比持续压低）、开源权重（K2 → K3 → K3.1 Pro 连续开放）、长程 Agent（13 小时编码 → 1M 上下文任务）
- **路线转向**：①K3.1 Pro 沿用 K3 架构仅加 RL 算力，与智谱"同基座后训练 Scaling"同范式——竞争重心从炼基座转向炼后训练；②定价下探（$3/$15 → $2/$10）+ 编码专精分档（K2.7-Code），从单一旗舰转向场景分流
- **差异化定位**：Agent 原生 + 长周期执行 + 多 Agent 协作，与 DeepSeek 的推理/训练效率路线形成中国开源双雄分野（见第七章）；风险点是始终思考无法关闭的轻量任务成本与超大模型自部署门槛（64 加速器级）

### 研究基因与影响力

- **创始人学术基因**：杨植麟为 XLNet/Transformer-XL 一作（论文引用超 22000 次），联创团队含 ShuffleNet 共同一作、Detectron2 作者——长上下文与高效架构的研究基因直接映射到 KDA/Muon 等工程选择
- **技术报告公开**：K2 技术报告（arXiv:2507.20534）、K3 架构细节经 platform.kimi.com 公开，关键技术论文清单见 [kimi-k-series.md](kimi-k-series.md)
- **开源生态影响**：K3 为 2.8T 级开源权重标杆（官方称首个），vLLM/SGLang/KTransformers 等主流推理栈 day-0 适配；开源权重与托管 API 的多模态能力差异（视频仅 API 支持）已经代码级验证，见系列文档
