FAQ 销售实战话术

一线销售最常遇到的 5 个问题

Q：DeepSeek-V4-Pro 只要 3 元/M 输入，你们 12 元太贵了？

A：理解，价格是 4 倍，但价值是 2-3 倍。Agent 场景不比单价，比任务完成率。Qwen3.7-Max 的 Terminal-Bench 2.0 是国产模型最高（69.7），35 小时长时执行已实测。DeepSeek-V4-Pro 没有公开的 Agent 长时运行数据。一个简单的算账：如果一个 Agent 任务用 DS 需要 3 轮 + 2 次人工介入，用 Qwen 1 轮搞定无人介入，Qwen 的综合成本反而更低。

另外，5 折活动期间 Qwen3.7-Max 输入仅 ¥6/M，差距已收窄至 2 倍。缓存命中更是低至 ¥0.6/M。

Q：我们在用 GLM-5.1，为什么要换？

A：单价便宜，但 Agent 场景不等于单价便宜就能用。① 上下文窗口：GLM-5.1 只有 128K，Qwen 是 1M——Agent 场景下 128K 很快打满，模型被迫丢失上下文，任务失败率飙升。② Terminal-Bench 2.0：Qwen 69.7 vs GLM 63.5，Agentic Coding 能力高 6.2 分。③ 长时执行：Qwen 35h 自主执行已实测，GLM-5.1 无公开 Agent 长时运行数据。④ GLM 输入 ¥6 确实只有 Qwen ¥12 的一半，但一个 Agent 任务 GLM 因为上下文不足可能失败 2-3 次，Qwen 1 次搞定，总账算下来 Qwen 反而更省。

Q：我们已经在用 Claude Code 接 Opus 了，为什么要切 Qwen？

A：零迁移成本，成本直降 60%+。Qwen3.7-Max 兼容 Anthropic API 协议，Claude Code 里只需改 ANTHROPIC_BASE_URL 和 AUTH_TOKEN 两个环境变量，代码零改动。Terminal-Bench 69.7 超 Opus 4.6 的 65.4，SWE-bench Pro 60.6 超 57.3。能力更强，价格更低——百炼 ¥12/M vs Anthropic $6.25/M（≈ ¥45/M），输入成本不到 1/3。

Q：Qwen3.7-Max 输出冗长，会不会反而更贵？

A：好问题，确实需要注意。评测中 Qwen 生成量是中位数的 4 倍。建议：① prompt 中显式约束输出长度；② 善用缓存（¥0.6/M，命中率极高）；③ 对不需深度推理的轻量场景，搭配 Qwen3.6-Flash 使用。即便如此，单价优势仍在——GPT-5.5 输出 ¥30/M（≈ ¥216/M），是 Qwen ¥36/M 的 6 倍。

Q：Qwen3.7-Max 怎么快速接入？

A：三步 5 分钟搞定。① 开通百炼平台，获取 DashScope API Key；② 在你的 AI Coding 工具（CC/Trae CN/CodeBuddy）或 Agent 平台（QoderWork/OpenClaw/Hermes）中，将 base_url 改为百炼地址、API Key 替换为 DashScope Key；③ 测试跑通。兼容 OpenAI 和 Anthropic 双协议，现有代码零改动。新用户赠送 100 万 tokens 免费体验。
