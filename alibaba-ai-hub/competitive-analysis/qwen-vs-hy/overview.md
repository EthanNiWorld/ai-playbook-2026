# Qwen4-Max / Qwen3.8-27B vs Hy4 竞争分析

> 最后更新: 2026-11-20
> 对比维度: 旗舰与开源双档布局 / Agentic Coding / 视觉与 Computer Use / 上下文 / 定价与部署
> 状态: Published

<!-- SUMMARY_START -->
**核心差异**: Qwen4-Max（2026-11-16 GA，取代 Qwen3.8-Max）以 Next 架构、1M 上下文、文本+图像+视频输入与任务级降本承担旗舰档，Qwen3.8-27B（开源版本）以 27B Dense 原生视觉语言、可关闭思考和较低部署门槛承接 GUI/视觉与私有化场景；Hy4 正式版同样进入 1M + 视觉 + Computer Use 阶段，并强化办公、金融和专业软件操作，但正式版权重尚未放出。
**我方优势**: Qwen4-Max 单价较上代降 25%（SG $1.5/$4.5）、AA 单任务成本 $3.27（较上代 -67%）、缓存命中 $0.075（= 输入价 5%）、非思考 128K / 思考+回答 256K 输出预算与 Max 档首次视频输入；27B 的开放权重、OSWorld-Verified 84.3、三个百炼端点实测及 `enable_thinking=False`；旗舰 API 与开源 Dense 小模型的双档组合。Qwen4-Max 当前代公开数据已覆盖 TB 4.0、DeepSWE、Work360 与 AA，但未公布 TB 2.1 / SWE-Pro，3.8-Max 旧分不继承。
**适用读者**: SA / 售前 / 产品经理

## 定位与规格对比

| 维度 | Qwen4-Max | Qwen3.8-27B（开源版本） | Hy4（正式版） |
|------|-------------|--------------------------|---------------|
| 厂商 | 阿里云 | 阿里云 | 腾讯混元 |
| 一句话定位 | 新一代旗舰（2026-11-16 GA）：代码工程、专业办公与长程 Agent | 开源 Dense 视觉语言，GUI/视觉与编程办公性价比档 | 1M 生产力旗舰，视觉理解 + Computer Use |

| 上下文 | **1M** | 262K | **1M**（最大输入 960K） |
| 最大输出 | 非思考 **128K**；思考+回答总预算 **256K** | 未公开 | 64K |

## 定价对比

> 以下均为每百万 tokens 刊例价。不同币种、区域和平台不可直接混算；实际采购应按目标节点、缓存命中率、思考长度与输出量核算总账单。

| 模型 | 节点 / 口径 | 输入 | 输出 | 缓存命中 |
|------|-------------|------|------|----------|

| Qwen4-Max | 百炼北京（国际站 USD） | $1.413 | $4.24 | $0.071 |
| Qwen3.8-27B（开源版本） | 百炼新加坡 | **$0.5** | $3 | 支持缓存折扣，单价未公开 |
| Qwen3.8-27B（开源版本） | 百炼北京 | $0.424 | $1.696 | 支持缓存折扣，单价未公开 |
| Hy4 | 腾讯云国内刊例 | ¥6 | ¥18 | ¥0.3 |
| Hy4 | 官方英文稿海外刊例 | ≈$0.90 | ≈$2.70 | ≈$0.045 |

- **Max vs Hy4**：按各自海外刊例，Hy4（≈$0.90/≈$2.70）仍约为 Qwen4-Max SG（$1.5/$4.5）的 6 折，但差距较 3.8 代（Hy4 约为 3.8-Max $2/$6 的一半）已收窄；Qwen4-Max 单价较上代降 25%、AA 单任务成本 $3.27（较上代 $10.02 降 67%）、缓存命中仅 $0.075，成本对比应转向任务总账单与缓存命中率，而非刊例单价。Qwen4-Max 北京参考价为 ¥10/¥30、缓存命中 ¥0.5。
- **27B vs Hy4**：按各自海外刊例，27B 输入价更低、输出价略高；两者节点与平台不同，且思考 token 消耗可能改变总成本，不能仅凭单价宣布胜负。
- **私有化成本**：27B 可按开放权重路线评估自建推理；**Qwen4-Max 本体闭源**，私有化旗舰短期仅 Qwen3.8-2.4T-A95B 可选；Hy4 正式版权重尚未放出，不能把 Hy4 preview 的 Apache 2.0 和部署方案直接套到正式版。

## SA 销售打法建议

### 我方优势切入点

1. **双档产品组合**：Qwen4-Max 覆盖旗舰代码工程与专业办公，27B 覆盖开源视觉、GUI 与私有化；Hy4 flash（2026-11-16）已补轻量档，但正式版与 flash 权重均未放出，自部署路径缺失不变。
2. **Qwen4-Max 的代际降本与规格证据**：单价较上代 -25%（SG $1.5/$4.5）、AA 单任务成本 $3.27（-67%）、缓存命中 $0.075（= 输入价 5%）、非思考 128K / 思考+回答 256K 输出预算、Max 档首次视频输入，适合围绕重度编码、长输出与多模态任务做价值验证；Work360 52.69 为自建口径须与 AA 并陈，TB 4.0 / DeepSWE 新数据须对齐版本和 harness，TB 2.1 / SWE-Pro 未公布，不引用 3.8-Max 旧分。
3. **27B 的生产可控性**：27B Dense、开放权重、三个百炼端点可调用，`enable_thinking=False` 实测有效，便于在时延、成本和部署方式之间做工程权衡。
4. **视觉不是单点能力**：Qwen4-Max 承担通用旗舰多模态并补齐视频输入（多模态 Agent 不再需 Flash/27B 分流视频流量），27B 承接 GUI/视觉专项，避免用单一旗舰价格覆盖所有视觉流量。

### 对方优势场景（需诚实应对）

- Hy4 已具备 **1M 上下文 + 图像理解 + Computer Use**，旧的“256K、纯文本、无 GUI”话术全部失效。
- Hy4 的 DeepSWE、SWE-Marathon、APEX-Agents 等厂商数据突出，办公协作、金融研究和专业软件操作有明确场景化投入。
- 按海外刊例，Hy4 ≈$0.90/≈$2.70 仍低于 Qwen4-Max SG $1.5/$4.5；需要用任务成功率、输出长度、缓存命中率和整体 token 账单证明 Qwen4-Max 的价值（其 AA 单任务成本已较上代降 67%）。
- 腾讯拥有 WorkBuddy、CodeBuddy、元宝、ima、企业微信等分发与数据回流渠道，生态协同是实际竞争力。

### 对方薄弱环节与采购验证点

- **正式版权重未放出**：不能把“计划开源”表述成“已开源、可自部署”。
- **第三方验证不足**：公开 benchmark 含内部任务集与多种 harness，采购前应使用客户真实任务做 shadow 压测。
- **轻量档已补、开源仍缺**：Hy4 flash 已于 2026-11-16 发布（国内 ¥0.5/¥2），高并发轻任务价格竞争加剧；但 flash 与正式版权重均未放出，Qwen 27B 的开放权重与可关闭思考差异化仍在。
- **输出上限差异**：Hy4 最大输出 64K，Qwen4-Max 非思考 128K、思考+回答总预算 256K；长报告、长代码生成场景应纳入验证。

### 禁用旧口径与推荐话术

- 不再使用“1M vs 256K”“Qwen 多模态 vs 混元纯文本”“Hy4 正式版 Apache 2.0 可自部署”。
- 不再引用 3.8-Max 的 SWE-Pro 67.7 等发布期分数作为 Qwen4-Max 能力证据（不继承）；不再使用“Hy4 Flash 尚未发布”的过期表述。
- TB 跨代对比只用 TB 4.0：Qwen4-Max 48.5（官方博客）vs Hy4 官方榜单 39.09%；不得把 3.8-Max 旧 TB 2.1 时期的 86.6 拿来与任何 TB 4.0 分数并列，也不把 OSWorld-Verified 84.3 与 OSWorld 2.1 78.9 直接比较。

> “Hy4 已经进入 1M、视觉和 Computer Use 阶段，在办公、金融和专业软件操作上值得认真评估。Qwen4-Max 的差异不只是单个旗舰分数，而是新一代旗舰的任务级降本（单价 -25%、AA 单任务成本 -67%、缓存命中仅输入价 5%）加上与 27B 的双档组合：前者承担复杂代码、专业办公与视频理解，后者以开放权重、可关闭思考和 GUI/视觉能力覆盖私有化与成本敏感流量。建议用同一批真实任务，同时比较成功率、时延、token 总账单和部署边界。”

## 底层逻辑

竞争已从 Qwen3.7 vs Hy3 时期的“上下文与模态代差”，转为同代 1M 多模态 Agent 的**任务级成本、模型组合、场景数据、交付形态与生态协同**之争。Qwen4-Max 与 Hy4 在旗舰层直接交锋，27B 则提供 Hy4 正式版当前尚未兑现的开放权重与较低部署门槛；销售重点应从参数口号与刊例单价转向真实任务 PoC 和总拥有成本。
