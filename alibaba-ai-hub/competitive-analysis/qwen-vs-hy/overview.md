# Qwen3.8-Max / Qwen3.8-27B vs Hy4 竞争分析

> 最后更新: 2026-11-10
> 对比维度: 旗舰与开源双档布局 / Agentic Coding / 视觉与 Computer Use / 上下文 / 定价与部署
> 状态: Published

<!-- SUMMARY_START -->
**核心差异**: Qwen3.8-Max 以 1M 上下文、代码工程与专业办公能力承担旗舰档，Qwen3.8-27B（开源版本）以 27B Dense 原生视觉语言、可关闭思考和较低部署门槛承接 GUI/视觉与私有化场景；Hy4 正式版同样进入 1M + 视觉 + Computer Use 阶段，并强化办公、金融和专业软件操作，但正式版权重尚未放出。
**我方优势**: Max 的 Terminal-Bench 2.1 86.6、SWE-bench Pro 67.7 与 128K 最大输出；27B 的开放权重、OSWorld-Verified 84.3、三个百炼端点实测及 `enable_thinking=False`；旗舰 API 与开源 Dense 小模型的双档组合。
**适用读者**: SA / 售前 / 产品经理
<!-- SUMMARY_END -->

## 定位与规格对比

| 维度 | Qwen3.8-Max | Qwen3.8-27B（开源版本） | Hy4（正式版） |
|------|-------------|--------------------------|---------------|
| 厂商 | 阿里云 | 阿里云 | 腾讯混元 |
| 一句话定位 | 旗舰代码工程、专业办公与长程 Agent | 开源 Dense 视觉语言，GUI/视觉与编程办公性价比档 | 1M 生产力旗舰，视觉理解 + Computer Use |
| 架构 | 2.4T MoE，激活参数未公开 | 27B Dense | 正式版未单列；渠道沿用 preview 的 770B/49B |
| 上下文 | **1M** | 262K | **1M**（最大输入 960K） |
| 最大输出 | **128K** | 未公开 | 64K |
| 输入模态 | 文本 + 图像（API 已实测；视频待确认） | 原生视觉语言，面向 GUI/视觉场景 | 文本 + 图像（首次支持视觉理解） |
| Agent 侧重点 | 代码工程、多工具协作、专业办公、复杂推理 | GUI/视觉 Agent、编程与办公端到端任务 | CLI + GUI 双通道 Computer Use，Blender/CAD 专项训练 |
| 思考模式 | 支持思考与非思考 | 混合思考可关闭，三个百炼端点实测一致 | 默认 `high` 深度思考 |
| 权重与部署 | 百炼 API；Max 本体权重开放状态未明确 | **开放权重 + 百炼 API**，支持私有化部署 | 当前 API 为主；正式版权重与 system card 尚未放出 |
| 典型优势场景 | 重度编码、大型仓库、长文档、复杂办公 | GUI/视觉、私有化、成本敏感、需关闭思考 | 办公协作、金融研究、专业软件操作、腾讯产品生态 |

> **代际口径**：Hy4 正式版发布于 2026-11-04，已不是 Hy3 的 256K 纯文本形态；Qwen3.7-Plus 已退出主推，GUI/视觉场景由 Qwen3.8-27B 承接，通用多模态由 Qwen3.8-Max 承接。

## 定价对比

> 以下均为每百万 tokens 刊例价。不同币种、区域和平台不可直接混算；实际采购应按目标节点、缓存命中率、思考长度与输出量核算总账单。

| 模型 | 节点 / 口径 | 输入 | 输出 | 缓存命中 |
|------|-------------|------|------|----------|
| Qwen3.8-Max | 百炼新加坡 | $2 | $6 | $0.25 |
| Qwen3.8-Max | 百炼北京 / 全球 | ¥12 | ¥36 | 以当期定价页为准 |
| Qwen3.8-27B（开源版本） | 百炼新加坡 | **$0.5** | $3 | 支持缓存折扣，单价未公开 |
| Qwen3.8-27B（开源版本） | 百炼北京 | $0.424 | $1.696 | 支持缓存折扣，单价未公开 |
| Hy4 | 腾讯云国内刊例 | ¥6 | ¥18 | ¥0.3 |
| Hy4 | 官方英文稿海外刊例 | ≈$0.90 | ≈$2.70 | ≈$0.045 |

- **Max vs Hy4**：按国内人民币刊例，Hy4 输入与输出均为 Max 的一半；Max 的差异化需由旗舰能力、128K 输出和实际任务成功率支撑。
- **27B vs Hy4**：按各自海外刊例，27B 输入价更低、输出价略高；两者节点与平台不同，且思考 token 消耗可能改变总成本，不能仅凭单价宣布胜负。
- **私有化成本**：27B 可按开放权重路线评估自建推理；Hy4 正式版权重尚未放出，不能把 Hy4 preview 的 Apache 2.0 和部署方案直接套到正式版。

## 场景化推荐

| 客户场景 | 推荐 | 原因 |
|----------|------|------|
| 企业级 Agentic Coding、复杂推理、专业办公 | **Qwen3.8-Max** | 旗舰定位，TB 2.1 86.6、SWE-Pro 67.7，支持 1M 上下文与 128K 输出 |
| 大型代码仓库、超长文档、长程多工具任务 | **Qwen3.8-Max / Hy4** | 两者均为 1M；按代码、办公或腾讯生态需求做同任务 PoC，不再宣称 Qwen 独占长上下文 |
| GUI/视觉 Agent + 私有化部署 | **Qwen3.8-27B（开源版本）** | 27B Dense 原生视觉语言、开放权重，OSWorld-Verified 84.3 |
| 需要关闭思考、控制时延与 token 成本 | **Qwen3.8-27B（开源版本）** | `enable_thinking=False` 三个百炼端点实测生效 |
| Blender / CAD 等专业软件操作 | **Hy4** | Computer Use 针对专业软件专项训练，是当前最明确的差异化场景 |
| 办公协作、金融研究、腾讯产品生态 | **Hy4** | WorkBuddy、金融众测与 CodeBuddy / 元宝 / ima 等生态协同更直接 |
| 必须自部署 Hy4 正式版 | **当前不可满足** | 正式版权重尚未放出；可改评 Qwen3.8-27B，不能用 preview 的开放状态替代正式版承诺 |
| 通用图像理解与图表/文档任务 | **Max / 27B / Hy4 同任务实测** | 三者均具备视觉能力，但模态边界、专项 benchmark 与成本不同，不宜只看厂商单项分数 |

## SA 销售打法建议

### 我方优势切入点

1. **双档产品组合**：Max 覆盖旗舰代码工程与专业办公，27B 覆盖开源视觉、GUI 与私有化；Hy4 正式版当前缺少已放权重的小模型和正式版自部署路径。
2. **Max 的公开能力证据**：TB 2.1 86.6、SWE-Pro 67.7、PaperBench 93.0，以及 128K 最大输出，适合围绕重度编码与长输出任务做价值验证。
3. **27B 的生产可控性**：27B Dense、开放权重、三个百炼端点可调用，`enable_thinking=False` 实测有效，便于在时延、成本和部署方式之间做工程权衡。
4. **视觉不是单点能力**：Max 承担通用旗舰多模态，27B 承接 GUI/视觉专项，避免用单一旗舰价格覆盖所有视觉流量。

### 对方优势场景（需诚实应对）

- Hy4 已具备 **1M 上下文 + 图像理解 + Computer Use**，旧的“256K、纯文本、无 GUI”话术全部失效。
- Hy4 的 DeepSWE、SWE-Marathon、APEX-Agents 等厂商数据突出，办公协作、金融研究和专业软件操作有明确场景化投入。
- 按国内刊例，Hy4 ¥6/¥18 相比 Max ¥12/¥36 更具价格吸引力；需要用任务成功率、输出长度和整体 token 账单证明 Max 的价值。
- 腾讯拥有 WorkBuddy、CodeBuddy、元宝、ima、企业微信等分发与数据回流渠道，生态协同是实际竞争力。

### 对方薄弱环节与采购验证点

- **正式版权重未放出**：不能把“计划开源”表述成“已开源、可自部署”。
- **第三方验证不足**：公开 benchmark 含内部任务集与多种 harness，采购前应使用客户真实任务做 shadow 压测。
- **轻量档尚未补齐**：Hy4 Flash 尚未发布，高并发轻任务与开源小模型档不如 Qwen 双档组合完整。
- **输出上限差异**：Hy4 最大输出 64K，Max 为 128K；长报告、长代码生成场景应纳入验证。

### 禁用旧口径与推荐话术

- 不再使用“1M vs 256K”“Qwen 多模态 vs 混元纯文本”“Hy4 正式版 Apache 2.0 可自部署”。
- 不把 TB 2.1 86.6 与 TB 4.0 44.4 直接比较，也不把 OSWorld-Verified 84.3 与 OSWorld 2.1 78.9 直接比较。

> “Hy4 已经进入 1M、视觉和 Computer Use 阶段，在办公、金融和专业软件操作上值得认真评估。Qwen 的差异不只是单个旗舰分数，而是 Max 与 27B 的双档组合：前者承担复杂代码和专业办公，后者以开放权重、可关闭思考和 GUI/视觉能力覆盖私有化与成本敏感流量。建议用同一批真实任务，同时比较成功率、时延、token 总账单和部署边界。”

## 底层逻辑

竞争已从 Qwen3.7 vs Hy3 时期的“上下文与模态代差”，转为同代 1M 多模态 Agent 的**模型组合、场景数据、交付形态与生态协同**之争。Max 与 Hy4 在旗舰层直接交锋，27B 则提供 Hy4 正式版当前尚未兑现的开放权重与较低部署门槛；销售重点应从参数口号转向真实任务 PoC 和总拥有成本。
