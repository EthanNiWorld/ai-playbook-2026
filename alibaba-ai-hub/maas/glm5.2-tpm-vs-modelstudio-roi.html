测算方法与口径

  • Model Studio 月成本 = 输入 tokens ×〔(1−命中率)×输入价 + 命中率×缓存价〕+ 输出 tokens × 输出价。
  • TPM 预留成本 = 预留KTPM ×（日价÷容量块）× 计费天数 × 折扣，为固定支出，与实际用量无关。
  • 跑满：预留容量在计费周期内 24h × 100% 利用，此时承载的 token 量即业务负载吞吐量。
  • 整体等效折扣（几折） = TPM成本 ÷ ModelStudio成本 × 10。<10 折即预留更省。
  • 分项折算：TPM 等效输入单价 = 输入预留成本 ÷ 原始输入 tokens；÷ Model Studio 对应单价 ×10 得该项「几折」。
  • 预留 KTPM 自动值（对齐控制台换算，实测 4/5 吻合）：输入 = ceil10[(输入长度×输入容量系数×命中率×0.25 + 输入长度×输入容量系数×(1−命中率)) × RPM]；输出 = ceil10[输出长度×输出容量系数×RPM]。ceil10 = 向上取整到 10 的整数倍（即控制台「阶梯系数」）。
  • 盈亏平衡利用率 = TPM成本 ÷ ModelStudio满载成本；低于该利用率时按量付费更划算。

计算逻辑参考 · 百炼控制台「创建 TPM 预留」换算

下图为百炼控制台 TPM 预留换算界面，本测算器的「业务负载 → 预留 KTPM → 报价」链路与之对齐。

  • 业务负载：RPM 500 · 输入 60k · 输出 0.5k · 缓存命中 80% → 换算「建议购买输入 12000 KTPM / 输出 250 KTPM」（已叠加阶梯系数）。
  • 换算公式：建议购买输入 KTPM = ceil10[(输入长度×输入容量系数×命中率×0.25 + 输入长度×输入容量系数×(1−命中率))×RPM]；本例 =（60×0.80×0.25 + 60×0.20）×500 = 24×500 = 12000（正好整十，无需进位；本测算器公式实测吻合）。
  • 报价映射：输入 $11.09 / 10 kTPM·天，输出 $3.88 / 1 kTPM·天 → 原价 ≈ $14,278 / 天（12000×1.109 + 250×3.88）。
  • 跑满口径：12000 KTPM 输入容量承载原始输入吞吐 500×60 = 30,000 KTPM（命中 token 仅按 0.25× 计容量，整体系数 0.2+0.8×0.25=0.4，30000×0.4=12000），故等效输入单价远低于按量输入价。
