## 一、核心原则

**永远推荐当前最新版本模型。** 原因：

1. **能力更强** — 新模型各项 benchmark 全面领先，客户实际体验立竿见影
2. **老模型不打折** — 历史版本不降价，花同样的钱不如直接用新的
3. **老模型限流无法扩容** — 资源优先保障新模型，老版本遇到瓶颈没有扩容路径

> 💡 **成本敏感场景**：可开通阿里云国际站账号，调用北京节点的模型，适合海外客户或需要额外吞吐补充的场景。

| **Qwen3.7-Flash** | IPC、审校、大批量打标、在线成本敏感型场景 | 1M上下文、极致性价比、低延迟高并发 | [查看定价](https://www.alibabacloud.com/help/en/model-studio/model-pricing) |

**选型口诀**：
- 需要**秒级响应**（对话/客服/VL识别） → **Plus**
- 需要**深度思考**（代码/分析/Agent/长链路任务） → **Max**
- 需要**极致性价比**（IPC/审校/大批量打标/高并发） → **Flash**
- 90%客户用 Plus 就够了，Max 是极端场景的旗舰保障，Flash 是成本敏感场景的最优解

> 📌 Qwen3.8-Max-Preview（2.4T MoE）已开放抢先体验，预览版无公开 benchmark/定价，正式版承诺开源权重。

## 三、LLM API 计费模式

| 模式 | 适用场景 | 说明 |
|------|----------|------|
| **按量付费**（默认） | 用量波动、初期验证 | 按实际 Token 用量计费，弹性伸缩；扩容需联系商务经理 T+1 按需申请 |
| **TPM 预留** | 恒定吞吐、核心业务不接受限流 | 预留固定 TPM（每分钟Token数）额度，保障业务稳定性，适合生产环境关键链路 |
| **PTU（Provisioned Throughput Unit）** | 高吞吐 + 高性能 | 专属算力单元，**1.5~2倍** Token/秒生成速度，适合对延迟和吞吐有极致要求的场景 |

> ⚠️ **PTU / TPM 预留支持的模型**：Qwen3.7-Max、Qwen3.7-Plus、GLM-5.1、DeepSeek-V4 等核心模型。

**PTU 核心优势**：
- 🚀 **高速**：生成速度达标准API的 1.5~2 倍
- 🔒 **独占**：专属资源，不受共享池波动影响
- 📈 **可预测**：固定吞吐，适合 SLA 承诺严格的业务
