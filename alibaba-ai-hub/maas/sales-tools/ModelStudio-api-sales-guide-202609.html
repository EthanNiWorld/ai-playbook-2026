大模型拓新策略 Migration Strategy
策略一 · 平切

同样模型，直接平切

客户正在使用的模型（DeepSeek 官网 / 智谱开放平台 / 月之暗面开放平台等），百炼均有同款在售，可无损平切，一套 API Key 统一纳管。

🎯 推理质量 — 同款模型、同版本，推理能力一致
💰 性价比 — 缓存命中计费、国际站 USD 定价、TPM/PTU 预留更优惠
🛡️ SLA — 阿里云企业级 SLA，PTU 专属算力保障吞吐稳定
⚖️ 合规 — 国内合规备案 + 数据安全，出海可用国际站节点
策略二 · 平替

海外 SOTA → 国产旗舰，追求降本

客户在用 Claude / OpenAI 等海外 SOTA，可用 Kimi-K3（编程）/ Qwen / GLM-5.3（coming soon）/ DeepSeek-V4 平替，同等任务大幅降本。

💸 降本 — 覆盖海外旗舰绝大多数主流场景，成本远低于按量付费
⚡ 时延 — 国内节点就近调用，网络时延显著低于海外 API
🔐 合规 — 数据不出境或出境合规方案可选，支付与网络无门槛
🔁 演进 — OpenAI 兼容协议，迁移零成本，后续可平滑升级

拓新话术

  • 同模型平切 — “模型一样、效果一样，价格更低、SLA 更有保障、合规更省心，为什么要分开维护？”
  • 海外 SOTA 平替 — “Claude / OpenAI 能做的，Kimi-K3 / Qwen / GLM-5.3 / DeepSeek 也能做，目标是把成本降下来。”
平切讲“零风险”，平替讲“降本增效”，双策略并进覆盖存量与增量客户。

选型口诀

  • 流量波动 / 初期验证 → 按量付费（零门槛起步）
  • 流量可预估、不能限流 → TPM 预留（容量刚性兑付）
  • 高吞吐 + 低延迟 → PTU（专属部署实例）
TPM 预留与 PTU 均按 kTPM 预付费、超额可自动溢出按量：前者保「稳定」，后者保「性能」。
