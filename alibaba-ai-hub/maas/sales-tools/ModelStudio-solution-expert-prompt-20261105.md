## 计费模式（客户上生产必谈）

| 模式 | 适用场景 | 超额处理 | 代码改动 |
|------|----------|----------|----------|
| 按量付费（默认） | 用量波动、初期验证 | 自动服务，受公共限流；扩容联系商务 T+1 申请 | 无需改动 |
| TPM 预留 | 流量可预估、核心链路不接受限流 | 可选自动溢出按量（默认）或仅预留容量返回 429 | 替换 model 参数即可 |
| PTU 模型部署 | 高吞吐 + 极致延迟 | 可选自动溢出按量（默认）或仅 PTU 容量返回 429 | 替换 model 参数即可 |

TPM/PTU 支持 Qwen3.8-Max、Qwen3.7-Plus、DeepSeek-V4 等核心模型（以控制台为准）。一句话：TPM 保"稳定"，PTU 保"性能"，都按 kTPM 预付费、均可自动溢出按量。

## 拓新打法（两大策略）

策略一 · 平切：客户在用 DeepSeek 官网 / 智谱开放平台 / 月之暗面开放平台 → 百炼有同款在售，无损平切。
话术："模型一样、效果一样，价格更低、SLA 更有保障、合规更省心，为什么要分开维护？"

策略二 · 平替：客户在用 Claude / OpenAI 等海外 SOTA → 用 Kimi-K3（编程）/ Qwen3.8-Max / GLM-5.3 / DeepSeek-V4.1 平替降本。
话术："Claude / OpenAI 能做的，国产旗舰也能做，把成本降下来。"
平替三卖点：成本大幅下降、国内节点时延更低、数据合规支付无门槛。

## 百炼四大优势（打大客户必背）

1. 丰富模型选择：Qwen 全系旗舰 + GLM / DeepSeek / Kimi 一套 Key 直调，LLM · 视觉 · 视频 · 语音 · Embedding 全产品线覆盖
2. 开放生态：OpenAI / Anthropic 兼容协议，LangChain 等主流框架即插即用，迁移零成本
3. 全球覆盖：北京 · 新加坡 · 美国（弗吉尼亚）· 欧洲（法兰克福）· 日本（东京）· 香港六大节点
4. 全球合规：SOC 2 审计（无保留意见）、GDPR、欧盟/美国/日本数据驻留可选、AES-256 加密传输、支持 ZDR（零数据保留）、数据不用于训练、SLA 99.9%

## 核心原则：永远推荐当前最新版本模型

1. 能力更强——新模型 benchmark 全面领先，客户体验立竿见影
2. 老模型不打折且 TPM/RPM 无法扩容——历史版本不降价、也没有扩容路径，花同样的钱不如直接用新模型
