## 产品原理解析

### 一句话定位

阿里 FunAudioLLM 团队研发的**工业级语音识别工具包**，开源 16K+ Stars，百炼平台当前**主推的 ASR 引擎**，一次调用完成语音识别、语音检测、标点恢复、说话人分离、情感检测、音频事件识别六大能力。

### 底层原理（通俗版）

FunASR 是一套完整的语音理解流水线：原始音频输入 → VAD 切分语音段 → ASR 转写为文字 → 标点恢复 → 说话人标注 → 情感/事件识别。旗舰模型 Fun-ASR-Nano 采用 LLM-ASR 架构（MoE，30B 参数），处理速度达 170x 实时，vLLM 加速可达 340x。

论文：[Fun-ASR Technical Report](https://arxiv.org/html/2509.12508v3)（arxiv:2509.12508）

### 百炼平台模型矩阵

| 模型 ID | API 接入 | 场景 | 状态 |
|---------|----------|------|------|
| **fun-asr** | HTTP 异步 | 录音文件识别（批量转写，≤12h/2GB） | 🚩 主推 |
| **fun-asr-flash-2026-06-15** | HTTP 同步 | ≤5 分钟音频，流式/非流式返回 | 🚩 轻量快速 |
| **fun-asr-realtime** | WebSocket | 实时流式识别（边说边出字） | 🚩 实时 |
| fun-asr-mtl | HTTP 异步 | 多语言增强版 | 在售 |

> **Qwen3-ASR**（qwen3-asr-flash-filetrans / qwen3-asr-flash-realtime）仍可在百炼调用，但 FunASR 是主推方向。

### 核心限制

| 限制项 | 具体值 | 说明 |
|--------|--------|------|
| 录音文件识别 | 单文件 ≤12 小时、≤2GB | 超大文件需拆分 |
| fun-asr-flash | ≤5 分钟音频 | 超长音频请用 fun-asr 异步版 |
| 上下文增强 | 仅 fun-asr-flash-2026-06-15 支持 | 其他模型不支持上下文增强 |

## 六大核心能力

| 能力 | 说明 | 典型场景 |
|------|------|----------|
| **语音识别（ASR）** | 端到端 ASR，50+ 语言，中文 7 大方言 + 26 种口音，自动语种检测 | 会议转写、字幕生成 |
| **语音检测（VAD）** | 毫秒级语音活动检测，自适应静音阈值 | 直播字幕、语音助手 |
| **标点恢复** | 自动添加标点 + 逆文本正则化（ITN） | 有声阅读、内容制作 |
| **说话人分离** | 自动识别"谁说了什么"，标注说话人 ID | 多人会议、客服质检 |
| **情感检测** | 识别开心/悲伤/愤怒/中性等情绪 | 客服质检、舆情分析 |
| **音频事件识别** | 检测背景音乐、掌声、笑声、哭声等 | 完整音频场景理解 |

## 语言覆盖

- **Fun-ASR-Nano（旗舰）**：31 语种，中文含 7 大方言 + 26 种地域口音
- **fun-asr 系列**：50+ 语言，中文含粤语、四川话等多种方言
- 支持自动语种检测与智能非人声过滤

## 适用边界分析

### ✅ 适用场景

| 场景 | 说明 | 典型客户/案例 |
|------|------|--------------|
| 会议批量转写 | 录音文件异步转写 + 说话人分离 | 企业办公、远程会议 |
| 实时字幕/直播转写 | WebSocket 流式识别，边说边出字 | 直播、在线教育 |
| 客服质检 | 情感检测 + 说话人分离 + 热词定制 | 呼叫中心、售后服务 |
| 多语言内容处理 | 50+ 语言 + 自动语种检测 | 跨境电商、全球化产品 |
| 私有化部署 | 开源 + OpenAI 兼容 API | 数据敏感型企业 |

### ❌ 不适用场景

| 场景 | 不适用原因 | 替代方案 |
|------|-----------|----------|
| 仅需基础转文字、成本敏感 | FunASR 六大能力过剩 | Qwen3-ASR（可过渡） |
| 超低延迟实时对话（<100ms） | WebSocket 仍有网络延迟 | 端侧 ASR 引擎 |

### ⚠️ 常见误解

| 误解 | 事实 |
|------|------|
| FunASR 只能做语音转文字 | 六大能力一次调用：ASR + VAD + 标点 + 说话人 + 情感 + 音频事件 |
| FunASR = Qwen3-ASR | 两者是独立模型系列，FunASR 来自 FunAudioLLM 团队 |

### 🕳️ 踩坑记录

| 日期 | 问题 | 场景 |
|------|------|------|

## 关键配置与最佳实践

- **录音文件识别**：HTTP 异步任务，适合大文件批量转写
- **实时识别**：WebSocket 流式协议，适合直播/客服等实时场景
- **OpenAI 兼容 API**：标准 `/v1/audio/transcriptions` 接口，LangChain、AutoGen、Dify、Coze 等框架零改动对接
- **热词定制**：通过预设词表提升专有名词识别准确率
- **SDK 支持**：DashScope SDK（Java/Python）

### FunASR 生态三大模型选型
