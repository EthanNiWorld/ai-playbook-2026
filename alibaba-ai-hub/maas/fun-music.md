## 核心能力与限制

### 核心能力

| 能力 | 说明 |
|------|------|
| 端到端音乐生成 | 输入歌词文本，自动完成作曲、编曲、演唱、混音，输出完整 MP3 |
| 性别控制 | 支持 `male` / `female` 选择歌手声线 |
| Prompt 约束（部分） | 在 prompt 前加严格约束指令可**部分改善**歌词保真度（实测从 112s→142s，保留更多原文段落） |

### 核心限制

| 限制项 | 具体值 | 说明 |
|--------|--------|------|
| 歌词保真度 | 低～中 | 模型将歌词视为创作素材，会删减段落、润色句子；即使加强 prompt 约束也无法完全避免 [来源: 用户口述] ⚠️ 待官方验证 |
| 指令遵循 | 不支持 | 理论上需要支持严格歌词控制，但目前产品尚未实现 [来源: 用户口述] ⚠️ 待官方验证 |
| Endpoint 限制 | 仅公共 endpoint | Workspace 专属 endpoint 需对应 API Key，普通 DashScope Key 返回 `Endpoint.AccessDenied` [来源: 用户口述] ⚠️ 待官方验证 |

## API 调用方式

### Endpoint

```
POST https://dashscope.aliyuncs.com/api/v1/services/audio/music/generation
```

> ⚠️ **注意**：必须使用标准公共 endpoint。Workspace 专属 endpoint（如 `llm-xxx.cn-beijing.maas.aliyuncs.com`）需对应 API Key，普通 DashScope API Key 会返回 `Endpoint.AccessDenied`。[来源: 用户口述] ⚠️ 待官方验证

### 请求参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model` | string | 是 | 固定为 `fun-music-v1` |
| `gender` | string | 否 | 歌手性别，可选值：`male` / `female` |
| `prompt` | string | 是 | 歌词内容（模型将其视为创作素材） |

> 📝 以上参数基于实测推断，完整参数列表请参考 [百炼官方文档](https://help.aliyun.com/zh/model-studio/)。[来源: 用户口述] ⚠️ 待官方验证

### 输出格式

| 属性 | 值 |
|------|-----|
| 音频格式 | MP3 |
| 采样率 | 48kHz |
| 声道 | 立体声（2 声道） |

### Demo 对比

| 维度 | Demo 1（基础调用） | Demo 2（加 Prompt 约束） | 变化 |
|------|-------------------|------------------------|------|
| 额外 Prompt | 无 | `请严格按照以下歌词演唱，不要修改任何文字：` | — |
| Request ID | `f4d64c10-...` | `b8e299a0-...` | — |
| 音频时长 | 112 秒（1 分 52 秒） | 142 秒（2 分 22 秒） | +30 秒（+27%） |
| 文件大小 | 1.7 MB | 2.2 MB | +0.5 MB |
| Token 消耗 | 430 input tokens | 448 input tokens | +18 |
| 歌词保真度 | **低** — 大幅删减+润色 | **中** — 部分保留，仍有润色 | 改善但不彻底 |

**结论**：加强 prompt 约束可部分改善歌词保真度，但无法根本解决模型的"创作素材"处理模式。
