## 产品原理解析

### 一句话定位

MuleRun 是一台 7×24 小时运行的**云端专属电脑**——不是聊天机器人，而是真正完成任务的 AI Agent [来源: mulerun.com]

### 底层原理（通俗版）

MuleRun 为每个用户分配一台云端计算机，Agent 在上面持续运行。你可以：
- **布置任务后离开**：今晚布置，明早收结果
- **设置持续监控**：Agent 7×24 监控指标，异常时自动行动
- **集体智能进化**：所有用户的工作流模式匿名化后形成知识库，平台越用越强 [来源: mulerun.com]

### 核心特性

| 特性 | 说明 | 来源 |
|------|------|------|
| **Always-On 专属云端主机** | Agent 运行在专属云端计算机上，7×24 全天候运行，关掉浏览器不中断任务 | mulerun.com |
| **Self-Evolving 集体智能** | 匿名化工作流模式和最佳实践持续学习，平台用户越多 Agent 越强 | mulerun.com |
| **Proactive 主动监控与行动** | 持续监控指标变化（网站状态、竞品价格、库存水平），异常时不只报警而是直接执行下一步动作 | mulerun.com |
| **Computer Use** | 可操作云端桌面应用，完成跨应用、跨文件、跨系统的操作 | mulerun.com |
| **HTML 网站生成与发布** | 支持生成 HTML 并直接发布为网站，可自定义域名 | 用户补充 |

| **云端 Drive + 本地存储** | 支持云端 Drive 存储和本地文件存储，电脑关机后任务继续执行 | 用户补充 |

### 底层架构差异

```
QoderWork: 用户本地电脑 → 本地 Agent 运行时 → 本地文件系统 + 沙盒环境
MuleRun:   用户（Web/iOS）→ 云端 Debian VM → 云端 Drive + Computer Use + 外部 Connectors
```

根本分歧在于**运行位置**（本地 vs 云端），由此决定：
- QoderWork 优势：**文件直连**（无需上传）、**隐私性**（数据不离本机，CN 版不出境）、**低延迟**
- MuleRun 优势：**持续性**（7×24 Always-On）、**规模化**（跨系统、全球化 43 国）、**多模态内建**（生图/生视频/网站发布）

### MuleRun（全球版）与骡子快跑（中国版）的关系

| 维度 | MuleRun（全球版） | 骡子快跑（中国版） |
|------|-------------------|-------------------|
| **定位** | 面向全球市场 | 面向中国大陆市场，类似"MuleRun CN" |
| **数据主权** | **数据出境**，存于海外云端 | **数据不出境**，存于国内 |
| **入口** | mulerun.com | 阿里云市场（market.aliyun.com） |
| **功能** | 全球 SOTA 模型 + 完整 Agent 能力 | 功能对齐 MuleRun，适配国内合规要求 |

> ⚠️ 以上 MuleRun/骡子快跑版本差异为用户补充信息，待官方验证。

### 场景化选型决策树

```
用户需求是什么？
├─ 需要操作本地文件（Excel/PPT/代码仓库）？
│   → QoderWork（本地文件直连）
├─ 需要 7×24 持续运行（监控/定时任务/自动化）？
│   → MuleRun（Always-On）
├─ 需要生成并发布网站？
│   → MuleRun（HTML 生成 + 自定义域名）⚠️ 待验证
├─ 需要生图/生视频？
│   → MuleRun（内置 SOTA 模型）⚠️ 待验证
├─ 数据绝对不能出境？
│   → QoderWork CN 或 骡子快跑（CN 版）
├─ 面向海外市场 / 跨国协作？
│   → MuleRun（全球版，43 国家覆盖）
└─ 编码相关日常工作？
    → QoderWork（Qoder IDE 生态优势）
```

**场景快速参考**：
- "帮我把这个 Excel 整理成 PPT" → **QoderWork**（本地文件直连）
- "每天早上 6 点帮我抓取竞品价格" → **MuleRun**（7×24 持续运行）
- "监控我的网站，宕机了自动切换" → **MuleRun**（Always-On + 主动监控）
- "帮我分析本地的代码仓库" → **QoderWork**（Qoder 生态优势）
- "帮我做一个落地页并发布上线" → **MuleRun**（HTML 生成 + 网站发布 + 自定义域名）⚠️
- "帮我生成一批产品宣传图/短视频" → **MuleRun**（内置 SOTA 生图/生视频模型）⚠️
- "帮我登录需要拖拽验证码的网站" → **MuleRun**（图形验证码拖拽能力强）⚠️

> ⚠️ **分析师观点（非官方立场）**：两个产品覆盖不同场景，不是替代关系——本地 Agent 优势在隐私和文件直连，云端 Agent 优势在持续性和规模。阿里云官方未公开发表过双产品战略意图的说明。
