## 产品原理解析

### 一句话定位

万镜一刻是阿里云构建的 **面向内容创作者的完整产品**，不是单纯的模型 API，而是集成了故事板、主体创作、剪辑、资产管理的工业化视频生产平台。当前首发集成阿里全系大模型，后续预计接入第三方视频/图像生成模型，平台本身的价值在于流程工具与资产管理而非绑定单一模型。

### 与通义万相的关系

- **通义万相（Wan）**：面向开发者的底层视频生成模型及 API 服务
- **万镜一刻**：基于万相模型构建的上层产品，无需编程即可使用

### 底层模型栈

**当前已集成（阿里全系）：**

| 模型 | 职责 |
|------|------|
| HappyHorse 1.1 | 视频生成核心模型（影视级光影、色彩与细节） |
| 万相 Wan 2.7 | 基础生成模型 |
| Qwen-image | 图像生成 |
| Z-image | 图像渲染 |

> 后续预计接入阿里以外的生视频、生图模型，平台定位为模型无关的创作工作流。

### 核心限制

| 限制项 | 具体值 | 说明 |
|--------|--------|------|
| 单段视频时长 | 3–15 秒 | 需通过分镜拼接实现长视频 |
| 分辨率上限 | 1080P | 720P / 1080P 可选 |
| 多素材联合输入 | 最多 9 张参考图 | 对比 Seedance 2.0 的 12 个素材仍有差距 |
| 音画同步 | 7 种语言配音 | 原生支持，唇形对齐 |
| 镜峰模式 / 企业级套件 | 即将上线 | 截至发布时部分高级功能尚未开放 |

## 五大核心功能模块

| 模块 | 功能描述 |
|------|----------|
| **AI 智能故事板** | 上传剧本/小说 → AI 自动拆解场景、对白、镜头时长 → 批量生成分镜画面，标注运镜和人物动作 |
| **无限画布** | 节点式可视化工作台，剧本/人设/分镜/图片/视频以节点拖拽编排，支持自然语言局部修改 |
| **AI 生成器** | 文生视频、图生视频、参考生视频、视频编辑四种模式，可选 720P/1080P，16:9 / 自由宽高比 |
| **企业协作** | 多成员同项目在线编辑、实时评论批注、分级权限（管理员/创作者/审核员）、项目归档快照 |
| **资产管理** | 角色/场景/道具/品牌模板统一云端存储，素材打标分类检索，版本管理，权限隔离 |

### 三大创作模式

1. **故事板模式**：专为剧情类短剧/漫剧打造，剧本 → 分镜 → 视频全自动
2. **无限画布模式**：面向广告创意、商品种草，高自由度节点编排
3. **Agent 模式**（灰度测试中）：内置编剧、导演、提示词工程师等多 Agent 协同，自然对话式成片

### 主体创作（核心差异点）

角色、场景、道具可先单独建出 **多视角主图**，存成项目的视觉档案，之后所有镜头调用同一套素材：
- 跨镜头不换脸、风格不漂移
- 一次性生成的素材变为可反复调用的资产
- 有效降低短剧团队的"抽卡"成本

## 定价模式

国际站（wonderclip.ai）采用 **会员计划 + 积分加油包** 的付费体系，美元计价。积分是平台消耗的唯一货币。

| 套餐 | 月费（限时折扣价） | 原价 | 赠送积分 | 积分单价 | 核心权益 |
|------|------------------|------|----------|----------|----------|
| 标准版 | $340/月 | $400 | 30,000 | $0.0113/积分 | 1080P 视频、4K 图片、批量生成、限时不限量资产、20 个子账号、**支持 API 接入** |
| 旗舰版 | $3,200/月 | $4,000 | 300,000 | $0.0107/积分 | 1080P 视频、4K 图片、不限量资产、200 个子账号、镜峰模式（即将上线） |
| 至尊版 | $9,000/月 | $12,000 | 900,000 | $0.01/积分 | 1080P 视频、4K 图片、1000 个子账号、镜峰模式 + 企业级套件（即将上线） |

**积分规则**：
- 新用户首次注册赠 **5 天标准版会员 + 1,000 积分**
- 会员套餐赠送积分有效期 **1 个自然月**，未用完自动清零
- 积分加油包有效期 **1 年**，需先订阅会员计划才能购买
- 同一时间仅能订购 **1 个**会员计划，加油包不限购

**积分消耗参考**（万相 2.7）：
- 720P 视频生成：**6 积分/秒**（标准版折合约 $0.068/秒）
- 1080P 视频生成：**10 积分/秒**（标准版折合约 $0.113/秒）
- 单次生成不满 5 秒按 5 秒算，超过 5 秒按实际秒数算
- 更多消耗明细见平台「积分消耗明细」页面

**API 接入**：标准版（$400/月原价）起支持纯 API 接入模式，可集成到企业自有工作流。

### 交付方式三条线

1. **工具平台**：直接使用万镜一刻 Web 平台
2. **全栈 API**：标准版起支持音视频创作 Skills 与 API，支持"被集成"到企业自有工作流
3. **品牌套件**：独立域名 + UI 的品牌专属空间，多工作室模式 + 权限隔离

## 使用流程

1. 使用阿里云账号登录 https://www.wonderclip.ai（新用户赠 5 天标准版 + 1000 积分）
2. **创建主体资产**（可选）：角色/场景/道具 → 生成多视角主图 → 存为视觉档案
3. **新建故事项目**：选择创作类型 → 上传/粘贴剧本或分镜脚本
4. **设置叙事与风格**：叙事方式（对白解说 / 第一人称）、画面风格（写实 / 国风 / 动漫 / 科幻）
5. **生成故事板与视频**：AI 自动生成分镜画面及视频片段，可手动调整
6. **在线剪辑导出**：添加字幕、配音、配乐 → 导出成片
